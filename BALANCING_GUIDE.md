# Guía de balance

El azar elige oportunidades; la decisión define el costo. Los pesos base son 10 para común, 6 para poco común, 3 para rara y 1 para legendaria. Una condición específica puede justificar aumentar un peso, nunca convertir una rareza en certeza.

## Reglas

- un efecto ordinario mueve de 1 a 4 puntos;
- un efecto de 5 o más necesita un costo claro;
- ninguna elección mejora todos los ejes;
- confianza, estado físico y reputación permanecen entre 0 y 100;
- goles, partidos, títulos y finanzas no pueden ser negativos;
- una carrera completa apunta a 55–90 acontecimientos.

Ejecuta `npm run simulate` después de cada lote. Investiga eventos sin apariciones, cadenas que no progresan y arquetipos que dominen más del 45% de las carreras.
